# Chúc mừng sinh nhật ebe Nhai Nhai — 27/10

Trang tĩnh (HTML/CSS/JS), chạy thẳng trên GitHub Pages, không cần build.

## Thêm ảnh vào thước phim
1. Chép ảnh vào thư mục `anh/` (đặt tên `anh-01.jpg`, `anh-02.jpg`… cho gọn).
2. Mở `cau-hinh-anh.js`, ghi đúng tên file và chú thích (nếu muốn).
3. Ảnh dọc tỉ lệ 4:5 hiển thị đẹp nhất. Nên giảm ảnh còn cạnh dài ~1200px để trang tải nhanh.

## Sửa lời chúc
Sửa đoạn `<section class="loi-chuc">` trong `index.html`.

## Đưa lên GitHub Pages
1. Tạo repo mới trên GitHub (Public), ví dụ `sinh-nhat-nhai-nhai`.
2. Đẩy toàn bộ thư mục này lên nhánh `main`.
3. Repo → Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
4. Sau 1–2 phút, trang có ở `https://<tên-github>.github.io/sinh-nhat-nhai-nhai/`.

Lưu ý: nhạc YouTube không phát khi mở file trực tiếp (`file://`). Muốn xem thử trên máy thì chạy
`python -m http.server 8000` trong thư mục này rồi mở `http://localhost:8000`.
